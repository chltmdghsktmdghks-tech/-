# 트럼펫 표본 출처(2026-09-16 교체)

**VSCO2 Community Edition** — Versilian Studios / sgossner
<https://github.com/sgossner/VSCO-2-CE> (Brass/Trumpet/sus)

**CC0(퍼블릭도메인)** — 상업적 사용 포함 제한 없음, 저작권료·크레딧
표기 의무 없음.

예전(University of Iowa) 표본은 세기 한 벌(ff)뿐이라 pp·mf·ff 세 파일이
전부 같은 녹음이었다. 여기서는 여리게(v1)·세게(v3) 두 세기가 실제로
갈린다(pp=v1, mf·ff=v3). 자리는 E3~G5(9군데)에서 F2~C5(10군데)로
바뀌었다 — 저음 쪽으로 조금 더 내려간다.

가져온 음: F2·G3·A#3·C3·D#3·D4·F4·A2·A4·C5(sus=지속음) × 세기 2벌
(v1·v3). 파일명의 `#`은 `s`로 적었다(`A#3` → `As3`).

`tool/prep_samples.dart` 로 22.05kHz 모노로 낮추고 5초로 잘라(afconvert
로 먼저 22.05kHz 변환) 용량을 줄였다.
